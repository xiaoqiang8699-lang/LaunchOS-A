# LaunchOS 第一次试用

这份说明只给你看。请按自己的理解完成，主持人不会提前告诉你该点哪里。

## 测试目标

请把你的应用通过 LaunchOS 发布到公网，并打开最终访问地址。

## 开始地址

打开主持人发给你的 LaunchOS 登录页。当前内部入口是 http://localhost:3000/login 。

使用主持人给你的账号登录。

## 你需要准备什么

- 一个可以登录的账号
- 你自己的代码仓库，并且这个仓库还没有在 LaunchOS 里用过
- 大约一段不被打断的时间
- 结束后能打开公网地址的浏览器

请使用你自己的真实项目。不要使用别人已经调通的示例仓库。

## 测试时请自己操作

从登录开始，到最后打开公网地址，请自己完成。

主持人会在旁边看，但不会提前提示下一步。

如果你一时不知道点哪里，先自己试一试。只有你明确说做不下去时，主持人才会帮忙。

## 遇到问题怎么办

先告诉主持人你卡在哪一步，以及页面上看到的原话。

不要刷新后假装没发生。页面上的报错也请留着给主持人看。

如果页面在问你是否确认费用，请按你自己的理解决定。看不懂就说看不懂。

## 完成后反馈

做完以后，无论成功还是没做成，请用 1 到 5 分回答下面五件事，并可以再写一句自由反馈：

1. 你知道下一步该做什么吗？
2. 费用确认是否清楚？
3. 上线失败时，你看得懂原因吗？
4. 你是否需要别人帮助才能完成？
5. 如果这是正式产品，你愿意继续使用吗？

1 分是很不同意或很不清楚，5 分是很同意或很清楚。
