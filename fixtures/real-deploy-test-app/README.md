# REAL_DEPLOY_TEST_APP

Minimal Node HTTP app for LaunchOS managed hosting acceptance.

- Runtime: Node
- Start: `npm start` → `node server.js`
- Port: `PORT` or 3000
- HTTP 200 body: `LaunchOS First Real Deploy`

This repository is a real project fixture. Do not treat `example/alpha-demo` as this app, and do not skip analysis.
